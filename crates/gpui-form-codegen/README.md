# gpui-form-codegen

Shared parsing and token-generation support for the `gpui-form` procedural
macros.

This is a workspace implementation crate. Application developers should use
[`gpui-form`](../gpui-form/README.md); proc-macro consumers that intentionally
avoid the facade can use
[`gpui-form-derive`](../gpui-form-derive/README.md).
